Project Overview

This project presents a proposed AWS cloud architecture for a fictional training company that provides an online portal for registered participants.

The design focuses on secure application hosting, participant records, private document storage, controlled administrator access and network protection.

The goal is to demonstrate how AWS services can work together to provide a secure and scalable cloud environment.

Business Requirements

The proposed environment is designed around the following business requirements:

100 Registered Participants
20 Concurrent Users
HTTPS Secure Website Access
Private Database and Documents

Proposed AWS Architecture

The architecture uses an Amazon Virtual Private Cloud (VPC) with public and private subnets to separate internet-facing services from internal application resources.

  • Amazon VPC: Provides network isolation and control.
  • Application Load Balancer: Receives public HTTPS traffic.
  • Amazon ECS with AWS Fargate: Runs application containers in private subnets.
  • Amazon RDS: Stores participant records in a private database.
  • Amazon S3: Stores uploaded participant documents privately.
  • AWS Certificate Manager: Supports HTTPS certificates.
  • Amazon CloudWatch: Supports monitoring and logging.

Security and Access Control

Security is a central part of the proposed design. Access is restricted according to the responsibilities of each user and application component.

  • HTTPS protects website traffic in transit.
  • Private database subnets prevent direct public database access.
  • IAM roles provide applications with only the permissions they require.
  • Multi-factor authentication helps protect administrator accounts.
  • Private S3 storage prevents anonymous access to uploaded documents.
  • Temporary, authorized access can be used when participants need documents.
  • AWS Systems Manager can provide controlled administrative access without exposing SSH to the internet.

Project Scope and Assumptions

This is an AWS architecture and security design exercise. It documents a proposed solution rather than a fully deployed production application.

The design assumes approximately 100 registered participants and 20 concurrent users. Actual capacity and costs would need to be confirmed through workload testing and AWS pricing estimates.

Important: No paid AWS infrastructure deployment is claimed as part of this project.
