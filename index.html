Secure Training Portal

A secure and scalable AWS cloud architecture design for a fictional training company.

Cloud Computing | Week 2 Practical Project | 28 November 2026

Project Overview

This project proposes a secure AWS environment for a training company that provides an online portal for registered participants. The design covers application hosting, private document storage, participant records, network security and controlled administration.

Business Requirements

100Registered participants
20Concurrent users
HTTPSPublic website access
PrivateDocuments and database

Architecture and Security

The proposed design uses an Amazon VPC with public and private subnets. An Application Load Balancer provides HTTPS access to the application. Application compute runs privately, while the participant database is isolated from direct public access.

Amazon S3 stores uploaded documents privately. IAM roles and least-privilege permissions control application access. Multi-factor authentication protects administrator access.

Design Scope and Assumptions

This is an architecture and security design exercise. No paid AWS infrastructure is required or claimed to have been deployed. The proposed configuration is designed around approximately 20 concurrent users.
